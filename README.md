Project Name: Photography Website

Author Name: Fiona Mbugua

Description
This project focuses on building a visually appealing photography website using core front-end development skills. It demonstrates the correct use of essential HTML elements such as headings, paragraphs, lists, images, and text formatting tags to structure content effectively. A custom CSS stylesheet is implemented to enhance the design, applying concepts like selectors, the box model, fonts, colors, borders, and pseudoclasses for interactive effects. Emphasis is also placed on proper planning and design before development, ensuring a well-organized workflow. Finally, the completed website is published using GitHub Pages, showcasing both technical proficiency and creativity in web design.
